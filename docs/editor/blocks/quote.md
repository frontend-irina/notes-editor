# Блок Quote

## Назначение

`Quote` — текстовый блок для цитаты или выдержки. Реализация надстройки над Tiptap должна повторять публичную модель, преобразования и поведение стандартного блока `quote` из BlockNote.

Основной источник: [BlockNote — Typography / Quote](https://www.blocknotejs.org/docs/features/blocks/typography#quote).

Связанные спецификации:

- [Идентификатор блока](../block-id.md);
- [Inline Content](../inline-content.md);
- [Formatting Toolbar](../toolbar.md);
- [Импорт и экспорт HTML](../html.md#quote);
- [Импорт и экспорт Markdown](../markdown.md#quote).

## Модель данных

```ts
type QuoteBlock = {
  id: string;
  type: "quote";
  props: {
    backgroundColor: string;
    textColor: string;
  };
  content: InlineContent[];
  children: Block[];
};
```

## Поля

### `id`

- Содержит UUID v7 согласно [block-id.md](../block-id.md).
- Не изменяется при редактировании цитаты, перемещении, nest/unnest или преобразовании совместимого блока в Quote и обратно.

### `type`

- Всегда имеет значение `"quote"`.

### `props`

| Свойство | Тип | Значение по умолчанию | Поведение |
| --- | --- | --- | --- |
| `backgroundColor` | `string` | `"default"` | Цвет фона блока. |
| `textColor` | `string` | `"default"` | Цвет текста блока. |

Quote намеренно не содержит `textAlignment`. Панель выравнивания не должна изменять Quote или добавлять в него отсутствующий prop.

Именованные цвета темы и произвольные поддерживаемые CSS-цвета обрабатываются аналогично BlockNote. Inline-цвет конкретного текстового фрагмента хранится в `content[].styles` и имеет визуальный приоритет над цветом уровня блока.

### `content`

- Содержит массив `InlineContent`.
- Поддерживает обычный текст, стандартные inline styles и ссылки.
- Пустая цитата представлена как `content: []`.
- Inline content сериализуется и нормализуется по правилам [inline-content.md](../inline-content.md).

### `children`

- Содержит вложенные блоки цитаты.
- Дочерние блоки не являются частью inline content цитаты.
- Вложенность не изменяет ID, props или content родительской цитаты.
- В Tiptap дочерние блоки должны храниться в том же `blockGroup`, который используется общей блочной схемой проекта.

## Создание

Quote можно создать:

- через slash menu;
- через `BlockTypeSelect` в Formatting Toolbar;
- горячей клавишей `Mod+Alt+Q`;
- input rule в начале редактируемого inline-блока;
- публичным API вставки или обновления блока.

В русской локализации пользовательское название блока — «Цитата». Поисковые aliases должны поддерживать словарь редактора; стандартные английские aliases BlockNote включают `quotation`, `blockquote` и `bq`.

## Преобразование блока

- Преобразовать в Quote можно текущий блок, если его schema content имеет тип `inline`.
- Преобразование non-inline или plain-content блока через shortcut должно возвращать `false` и не менять документ.
- Совместимые inline content и marks сохраняются.
- Существующие `children` сохраняются.
- ID исходного блока сохраняется.
- Props, которых нет в схеме Quote, удаляются.
- Неуказанные `backgroundColor` и `textColor` получают значение `"default"`.

При преобразовании Quote в другой inline-блок также должны сохраняться ID, inline content, применимые styles и children.

## Горячая клавиша

| Действие | Сочетание |
| --- | --- |
| Преобразовать текущий inline-блок в Quote | `Mod+Alt+Q` |

`Mod` означает `Cmd` на macOS и `Ctrl` на Windows/Linux.

Требования:

- shortcut работает при focus внутри редактора;
- при успешном преобразовании обработчик возвращает `true`;
- при неприменимом selection обработчик возвращает `false`;
- shortcut выполняет ту же команду, что и выбор Quote в `BlockTypeSelect`;
- одна команда создаёт не более одной смысловой операции undo/redo;
- в read-only режиме shortcut не изменяет документ.

## Input rules

В начале блока следующие последовательности преобразуют текущий inline-блок в Quote:

| Ввод | Условие |
| --- | --- |
| `> ` | Символ `>` и пробел введены в начале блока. |
| `<quotation-mark> ` | Любой символ Unicode-категории `Quotation_Mark` и пробел введены в начале блока. |

Примеры второй группы: `" `, `' `, `« `, `» `, `“ `, `” `, `„ `.

После срабатывания input rule:

- служебный маркер и следующий за ним пробел удаляются из content;
- текущий блок получает тип `quote`;
- ID блока сохраняется;
- совместимые props и остальной inline content сохраняются согласно общей механике преобразования;
- операция отменяется одним undo;
- правило не срабатывает в середине текста;
- правило не срабатывает для блока, который не поддерживает преобразование в inline Quote;
- во время IME/composition правило не должно нарушать ввод пользователя.

Поведение с Unicode quotation mark повторяет фактическую input rule BlockNote. Оно шире традиционного Markdown-синтаксиса `> `.

## Редактирование

Quote использует общие операции редактирования inline-блоков:

- ввод и удаление inline content;
- применение и снятие текстовых styles;
- создание и изменение ссылок;
- разделение блока клавишей `Enter`;
- объединение с соседним совместимым блоком на границе;
- выделение через несколько блоков;
- копирование, вырезание и вставка;
- nest/unnest;
- drag-and-drop;
- undo/redo.

Quote имеет `isolating: false`: границы блока не должны искусственно запрещать общие операции объединения, удаления и перемещения selection, разрешённые блочной схемой.

Пограничное поведение `Enter`, `Backspace` и `Delete` должно быть сравнено с BlockNote в рамках будущей общей спецификации клавиатурного поведения. До её появления Quote не должен вводить собственные отклонения от стандартных inline-блоков BlockNote.

## Formatting Toolbar

При выделении текста внутри Quote Formatting Toolbar работает по правилам [toolbar.md](../toolbar.md).

- Доступны поддерживаемые inline styles и работа со ссылками.
- `BlockTypeSelect` отображает Quote как текущий тип и позволяет выполнить допустимое преобразование.
- `ColorStyleButton` меняет inline-цвета selection, а не props Quote.
- Кнопки `TextAlignButton` для Quote скрыты или недоступны, поскольку блок не имеет `textAlignment`.
- Nest/unnest выполняет структурное перемещение без изменения ID.

## Импорт и экспорт

Правила преобразования Quote не дублируются в спецификации блока:

- отображение `<blockquote>`, импорт, Full HTML, Interoperable HTML, сохранение
  props и HTML round trip определены в [html.md](../html.md#quote);
- CommonMark blockquote, импорт и экспорт `>`, многострочные и вложенные цитаты,
  lossy-преобразования, diagnostics и Markdown round trip определены в
  [markdown.md](../markdown.md#quote).

При конфликте профильная спецификация формата является источником истины.

## Пример JSON

```json
{
  "id": "0198f123-4567-7abc-8def-0123456789ab",
  "type": "quote",
  "props": {
    "backgroundColor": "default",
    "textColor": "default"
  },
  "content": [
    {
      "type": "text",
      "text": "Цитируемый текст",
      "styles": {}
    }
  ],
  "children": []
}
```

## Граница ответственности

Quote определяет:

- собственный type и prop schema;
- shortcut и input rules преобразования в Quote.

Quote не определяет:

- общую генерацию UUID v7;
- внутреннюю модель inline content;
- реализацию Formatting Toolbar;
- общие алгоритмы nest/unnest, drag-and-drop и multi-block selection;
- общую историю undo/redo.

Эти возможности должны переиспользоваться из соответствующих слоёв редактора.

## Критерии приёмки

1. Публичное JSON-представление Quote соответствует модели BlockNote и содержит только `backgroundColor` и `textColor` в props.
2. Значения обоих props по умолчанию равны `"default"`.
3. Quote поддерживает `InlineContent[]`, ссылки и стандартные inline styles.
4. Пустая цитата сериализуется с `content: []`.
5. `Mod+Alt+Q` преобразует совместимый inline-блок в Quote и сохраняет его ID, content и children.
6. Shortcut не изменяет non-inline, plain-content или read-only документ.
7. Ввод `> ` в начале блока преобразует его в Quote и удаляет маркер.
8. Ввод Unicode quotation mark и пробела в начале блока повторяет соответствующую input rule BlockNote.
9. Input rule не срабатывает в середине текста и отменяется одной операцией undo.
10. Formatting Toolbar не предлагает изменение `textAlignment` для Quote.
11. Редактирование, перемещение и nest/unnest не изменяют ID блока.
12. Преобразование Quote в другой совместимый inline-блок сохраняет content, children и ID.
13. Undo/redo восстанавливает создание, преобразование, форматирование и структурные изменения Quote.

## Вопросы для проверки по эталону

Перед объявлением полной совместимости необходимо сравнить с актуальным BlockNote:

- какой тип получает новый блок после `Enter` в начале, середине и конце Quote;
- поведение `Backspace` в пустом Quote и на его первой позиции;
- распределение `children` при разделении Quote;
- срабатывание Unicode input rule для парных закрывающих кавычек и апострофов в разных раскладках.

Результаты сравнения должны быть добавлены в эту спецификацию.
