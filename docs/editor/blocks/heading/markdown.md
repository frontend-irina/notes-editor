# Markdown для блока Heading

## Назначение

Документ определяет импорт и экспорт блока `heading` между публичной моделью
редактора и Markdown.

Общие правила формата, безопасности, diagnostics и lossy-преобразований описаны в
[общей спецификации Markdown](../../markdown.md). Модель блока определена в
[heading.md](./heading.md), а inline-разметка — в
[inline-content.md](../../inline-content.md).

## Представление

Heading экспортируется в ATX-форме: уровень задаётся количеством символов `#`
перед текстом.

```md
# Заголовок первого уровня

## Заголовок второго уровня
```

Уровни `1`–`6` соответствуют префиксам `#`–`######`. Между префиксом и
содержимым обязателен пробел. Экспорт не использует Setext-синтаксис (`===` и
`---`), чтобы представление всех уровней было единообразным.

## Импорт Markdown

- ATX heading уровней 1–6 создаёт `HeadingBlock` с соответствующим `props.level`.
- Setext heading может импортироваться как level 1 или 2, если его поддерживает
  общий Markdown parser.
- Импортированный блок получает новый UUID v7, поскольку Markdown не хранит `id`.
- `backgroundColor`, `textColor` и `textAlignment` получают default-значения.
- Текст и поддерживаемая inline-разметка преобразуются в `InlineContent[]`.
- Heading без видимого текста импортируется с `content: []`.
- Более шести `#` в начале строки не создают Heading и сохраняются как текст
  Paragraph согласно правилам используемого Markdown-диалекта.
- Необязательные закрывающие `#` не входят в видимый текст, если parser распознал
  их как часть ATX heading.

## Inline content

Внутри Heading действуют общие Markdown mappings:

| Markdown | Публичное inline-представление |
| --- | --- |
| `**text**` / `__text__` | `StyledText` с `bold: true` |
| `*text*` / `_text_` | `StyledText` с `italic: true` |
| `~~text~~` | `StyledText` с `strike: true` |
| `` `text` `` | `StyledText` с `code: true` |
| `[label](href)` | `Link` |
| обычный текст | `StyledText` со `styles: {}` |

Соседние фрагменты с одинаковыми styles нормализуются. Некорректная inline-
конструкция по возможности сохраняется как читаемый текст.

## Экспорт Markdown

- Перед содержимым выводятся `level` символов `#` и один пробел.
- Поддерживаемые `bold`, `italic`, `strike`, `code` и `Link` преобразуются в
  соответствующую Markdown-разметку.
- `underline`, inline colors и background colors не имеют переносимого
  CommonMark-представления и теряются с warning.
- `id`, block colors и `textAlignment` не экспортируются.
- Пустой Heading экспортируется как префикс его уровня с завершающим пробелом либо
  эквивалентная нормализованная форма, которую повторный импорт распознаёт как
  Heading того же уровня.
- Соседние blocks разделяются пустой строкой в нормализованном выводе.

## Дочерние блоки

Markdown heading задаёт раздел документа, но не кодирует `children` блочной
модели напрямую.

- `children` не входят в inline-содержимое Heading.
- При lossy-экспорте дети выводятся после Heading как последовательные blocks без
  исходной вложенности, аналогично BlockNote.
- Потеря вложенности сопровождается warning расширенного API.
- При повторном импорте эти blocks становятся соседними, если общий импортёр не
  реализует отдельное восстановление структуры документа.

## Round trip

Для простого Heading гарантируется семантический цикл:

```text
HeadingBlock → Markdown → HeadingBlock
```

Сохраняются тип, `level`, видимый текст, поддерживаемые inline-стили и ссылки.
Не сохраняются исходный `id`, block props, неподдерживаемые inline-стили и
вложенность `children`.

## Критерии приёмки

1. `# `–`###### ` импортируются как Heading уровней 1–6.
2. Импортированный Heading получает UUID v7 и default props.
3. Экспорт использует ATX-префикс, соответствующий `level`.
4. Поддерживаемое inline content преобразуется без потери видимого текста.
5. Пустой Heading после round trip сохраняет тип и уровень.
6. Уровень вне диапазона 1–6 не создаёт некорректный `HeadingBlock`.
7. Потеря props, unsupported styles и вложенности отражается в warnings.
8. Round trip сохраняет семантику простого Heading.

## Открытые вопросы для проверки по эталону

- импорт и нормализация Setext headings;
- точная форма экспорта пустого Heading;
- обработка закрывающих `#` и пробелов после них;
- сохранение ведущих и завершающих пробелов содержимого;
- экспорт Heading с hard break и вложенными blocks.
