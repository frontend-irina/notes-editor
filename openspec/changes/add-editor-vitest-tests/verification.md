# Проверка реализации

Дата: 2026-09-09. Реализованы тесты всех исполняемых модулей редакторов и согласованные исправления выявленных регрессий. Отдельная browser regression остаётся открытой: подключённого браузера нет.

## Реализовано

- Vitest 5.0.0 и coverage-v8 5.0.0, jsdom 29.1.1, React Testing Library с user-event/jest-dom как devDependencies.
- Конфигурация, команды, отдельная типизация, cleanup, реальные EditorState/Editor, fixtures и контролируемые DOM/DataTransfer API.
- 54 соседних тестовых файла для исполняемых модулей области изменения и 2 файла проверки инфраструктуры.
- Матрица в [testing.md](../../../docs/architecture/testing.md), актуальные README, архитектура и индекс docs/agent.md.
- Inventory обнаруживает исполняемые файлы без соседнего теста; coverage исключает только тесты и подтверждённые AST файлы без исполняемой логики.

## Согласованные исправления

1. Inline styles сравниваются по ключам/значениям, независимо от порядка marks. Соседние совместимые фрагменты объединяются согласно действующей спецификации.
2. Специализированные HTML parse rules bullet/numbered/check имеют priority 100 и распознаются перед generic listItem из StarterKit.
3. Межредакторный Slice восстанавливается через schema получателя перед расчётом dropPoint и вставкой. Некорректные или неизвестные типы отклоняются без удаления источника.
4. History selector использует текущий prop editor, устраняя старое состояние доступности undo/redo после замены экземпляра.
5. Меню типа блока и цвета используют стандартный Portal MUI и не оказываются внутри aria-hidden родительского контейнера.

Пользователь согласовал исправления последовательно в разговоре. Публичные типы и runtime-зависимости не менялись; новые продуктовые требования не вводились. Прежние падавшие тесты оставлены активными и теперь проходят.

## Границы проверки

BubbleMenu внешнего пакета заменён в тесте оболочки: проверяется shouldShow, реальные внутренние editor/menu/toolbar и persistence. Layout не проверяется. IME guard вызывается непосредственно: одиночный синтетический KeyboardEvent не воспроизводит полноценную композицию браузера. DataTransfer и координаты моделируются, transactions и schema остаются настоящими.

Два вызова `cua.getState()`, включая финальный после согласованных исправлений, вернули `{"apps":[],"browsers":[]}`. Нативный drag, реальный focus/IME, визуальные меню и browser persistence/undo/redo не проверены. Для них открыта задача 8.5. Задачи 5.3/8.1 предыдущего рефакторинга не закрывались.

Непокрытые ветки преимущественно относятся к защитным проверкам неподходящего selection/schema, редким defaults, отдельным вариантам UI callbacks и состояниям внешних библиотек. Наличие высокого покрытия не означает полной совместимости с BlockNote; обязательные browser-сценарии остаются отдельной проверкой.
