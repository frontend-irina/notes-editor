# Проверка рефакторинга модулей

## Исходная версия

Baseline: `b481cc2f1d04a8e7109eccec6d73719c3f4344a4`.
До изменения `npm.cmd run lint` и `npm.cmd run build` прошли. Сборка предупреждала о чанках крупнее 500 kB; это предупреждение осталось и после изменения.

## Выполненные проверки

Из корня репозитория:

```text
node openspec/changes/refactor-editor-modules/verify-refactor.cjs
npm.cmd run lint
npm.cmd run build
```

Все команды завершились с кодом 0.

Сравнительный стенд использует уже установленный TypeScript для загрузки модулей, исходники baseline из Git и текущие исходники. Новые зависимости и тестовый фреймворк не добавлялись. Результат: **101 сравнение**, **69 TS/TSX-файлов**, **0 циклов**, **0 файлов TS/TSX длиннее 150 строк**. Отдельный подсчёт TS/TSX/CSS также не обнаружил превышений 150 строк. Максимум — `serialization/blocks.ts`, 129 строк.

Покрыты:

- Совпадение порядка и приоритетов extensions; настройки StarterKit сохранены при переносе.
- Преобразования всех шести типов блоков с вложенностью, marks, цветами, ссылками, level/start/checked, пустым содержимым и fallback.
- Enter paragraph/heading/quote на пустых и непустых блоках, в начале/середине/конце, с выделением и вложенностью; сравниваются steps, документ, selection и результаты undo/redo.
- Удаление пустого блока, восстановление отсутствующих и дублирующихся ID.
- Slash trigger, query, выполнение шести типов пунктов меню, ArrowUp/Down, PageUp/Down, Escape, Enter.
- Вычисление выделенного диапазона, клавиатурное перемещение и транзакции drop внутри одного и между двумя EditorState, включая drop в исходный диапазон.
- Storage с пустым, корректным, повреждённым и недоступным хранилищем.
- Равенство наборов CSS-селекторов, деклараций и условий media queries до/после распределения по файлам.
- Разрешение относительных TS/TSX-импортов и отсутствие циклов.

Сравнение транзакций использует настоящий ProseMirror EditorState, но стаб EditorView. Генерация UUID подменена детерминированной функцией для сравнения новых ID; реализация `uuid.ts` не менялась. В проверках drop сессия подставляется в памяти стенда, preview заменён счётчиком удаления. Storage проверяется со стабом localStorage. Эти проверки подтверждают эквивалентность на уровне кода и транзакций, а не нативные события браузера.

## Браузерные проверки не выполнены

Браузерный коннектор не предоставил подключённых браузеров. Computer Use отказал в управлении Яндекс Браузером из-за неподдерживаемого контроля URL; доступ к Edge не был одобрен. По указанию пользователя реализация и доступные проверки выполнены независимо от этого ограничения.

Не проверены: нативный drag-and-drop и реальный preview, фокус/selection в React UI, prompt и composition, клики `+`, ARIA в живом DOM, внешний вид и каскад на узком/широком экране, реальный localStorage после перезагрузки, консоль браузера. Соответствующие задачи 5.3 и 8.1 оставлены незавершёнными. Изменение не архивировано.
